===================================================
HOW TO USE
===================================================

1. Initialize a lab:
   const labService = new LabService()
   labService.initializeLab('lab-vlan-trunk', 'user-123', VLAN_TRUNK_LAB)

2. Run a checkpoint step:
   const result = await labService.runLabStep(
     'lab-vlan-trunk',
     'user-123',
     'enable',
     'Password: '
   )

3. Get progress:
   const progress = labService.getLabProgress('lab-vlan-trunk', 'user-123')
   console.log(`${progress.percentComplete}% complete`)

4. Submit lab:
   const submission = labService.submitLab('lab-vlan-trunk', 'user-123')
   console.log(`Score: ${submission.overallScore}%`)

5. Get hints:
   const hint = labService.getHint('lab-vlan-trunk', 'user-123', 1) // L1 hint
